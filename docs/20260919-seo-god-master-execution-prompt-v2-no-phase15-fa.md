Replace rigid five-phase wave locking with two dependency types:

### HARD dependency
A phase is blocked only when the missing upstream state can make its write unsafe, logically invalid, or impossible to verify. Examples: writing to a resource without a current snapshot; changing a product decision module without verified product identity; publishing a data claim without evidence.
